# Meu Tempo — UFG

Protótipo acadêmico de Design Thinking para a disciplina Empreendedorismo I.

## Conteúdo

- `index.html`: entrada do projeto.
- `app/`: protótipo com login fictício, agenda e reorganização de imprevistos.
- `apresentacao/`: apresentação de até 8 minutos, com cronômetro compartilhado.
- `roteiro/`: falas, tempos e percurso da demonstração.

Os dados acadêmicos foram transcritos dos materiais fornecidos pelo grupo. A rotina pessoal é ilustrativa e editável. Não existe autenticação real, integração ativa ao SIGAA ou coleta de credenciais. As alterações do visitante são locais ao seu navegador.

Votos e notas preparatórias estão identificados e devem ser confirmados pelo grupo. Não são resultados de teste com usuárias.

Site estático, sem dependências ou etapa de construção. GitHub Pages: publicar a raiz da branch `main`.
